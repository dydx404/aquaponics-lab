# 任务书 · 标准节点底板 PCB（node-baseboard）

> 负责人：硬件协作者（远程）· 分支：`hw/node-baseboard` · 交付到本目录
> **状态：✅ 放行开工。** 功能已固化（见 [functional-spec](../../../docs/functional-spec.md)）、接口契约 v2 与连接器方案已定。**开发板选型 + PCB 设计都由你决定**；唯一约束：开发板是 **ESPHome 兼容的 ESP32 家族**。

## 0. 一句话

设计一块**全项目通用的 ESP32 节点底板**，把[接口契约](../../../docs/handbook/13-interfaces.md)"焊进铜箔里"。以后每个模块（鱼缸节点、供电节点、种植节点…）都插这块板 → 接线统一、即插即用。

## 1. 背景（先读这些）

本项目是一个模块化的智能鱼菜共生平台，"一模块一个 ESP32 节点，统一 MQTT 接入"。你负责的是**节点的硬件底座**。开工前请读：

- 手册 [第 3 章 系统架构](../../../docs/handbook/03-architecture.md)（看全局）
- 手册 [第 6/7/8 章 供电/传感/执行](../../../docs/handbook/06-power.md)（电子原理）
- 手册 [第 13 章 接口契约](../../../docs/handbook/13-interfaces.md) ⭐（**你的边界，必须遵守**）
- 手册 [第 15 章 工作流](../../../docs/handbook/15-workflow.md)（怎么提交）

## 2. 你的边界（唯一硬约束）

**只要板子对外满足下面的接口契约 v1，板子内部怎么设计都随你。** 改契约要走 ADR + 双方确认；不改，你自由发挥。

| 边界 | 规定（v1 冻结） |
|---|---|
| 供电输入 | 12V DC（红 +12V / 黑 GND，来自太阳能+电池） |
| 板上电源 | DC-DC 降 5V（给 ESP32 + 5V 传感）；逻辑 3.3V |
| 逻辑电平 | 3.3V（ESP32）。**传感轨默认 3.3V；5V 器件的电平转换由本板做**（默认带转换，见 [ADR-0007](../../../docs/decisions/0007-sensor-rail-and-level-translation.md)） |
| 数字传感 | I²C 优先（SDA/SCL，带上拉，**只在盒内 ≲30cm**，见 [ADR-0006](../../../docs/decisions/0006-i2c-cable-limits.md)）；模拟量一律经 ADS1115 |
| 连接器 | 板内传感用 **JST-XH 2.5mm**（1-Wire 3P、I²C 4P）；pH/EC 走 **BNC→模块**。**v0.1 板级对外先用端子排/排针，GX 定型后再上**（一壳一信号防误插，见 [ADR-0007](../../../docs/decisions/0007-sensor-rail-and-level-translation.md)） |
| 大功率负载 | **主泵走市电 220V，不上这块板**：板上 MOSFET 只驱动 12V 轻载(阀/风扇/灯)；要控泵只出一路"控制信号"给外部继电器/SSR（见 [ADR-0004](../../../docs/decisions/0004-power-domains.md)） |
| 感性负载 | 低边开关用逻辑电平 MOSFET（IRLZ44N），**每路必带续流二极管** |
| 安全 | 12V 输入加保险 + 防反接；失电默认态在丝印标注（加药类默认关） |

## 3. 板子规格（MoSCoW）

### Must（最小可交付，做到这块板就有用）
- [ ] 12V DC 输入：保险 + 防反接（如串联肖特基或 P-MOS）
- [ ] DC-DC 降压 12V→5V（≥2A 裕量，给 ESP32 + 传感）
- [ ] 开发板座（**开发板选型你定**，ESPHome 兼容 ESP32 家族；DevKit/模组/自带均可）
- [ ] I²C 总线引出（含上拉电阻）到通用排针/端子（**连接器无关，先不焊死 GX**）
- [ ] 1-Wire header（DS18B20 温度，含上拉）
- [ ] **≥2 路低边 MOSFET 驱动**（IRLZ44N + 续流二极管 + 栅极下拉 + 12V **轻载**端子；主泵走市电不在此板）
- [ ] **≥6 路调理数字输入**（浮球/漏水等干接点）：外部上拉（GPIO34–39 无内部上拉必须板上给）+ RC 滤波 + 限流 + 钳位；含 **≥2 路 5V 容忍脉冲输入**（YF-S201 流量、超声波 Echo，经电平转换）。见 [ADR-0008](../../../docs/decisions/0008-node-io-provisioning.md)（MVP-4 验收前提）
- [ ] 电源指示灯 + 丝印标注所有接口/极性/引脚

### Should（有余力就上）
- [ ] 板载 ADS1115 位（可选贴装，给 pH/EC/浊度）
- [ ] **预留执行器位**（可选贴装，据 [functional-spec](../../../docs/functional-spec.md) B 类）：~4 路 12V MOSFET（打氧/加药/风扇/灯）、2 个舵机/PWM 头（喂食/遮阳）、2 路外部继电器控制输出（220V 泵/气泵）、WS2812 口、SPI 排针（未来触摸墨水屏终端）
- [ ] 1 路电流监测 INA226（测总线电流）
- [ ] JST-XH 传感口、安装孔、清晰丝印

### Could（加分/长线）
- [ ] 每路电流采样、栅极驱动、TVS/snubber 防护
- [ ] 板载状态灯（WS2812）或扩展排针
- [ ] 项目 KiCad 符号/封装库（复用件）
- [ ] 板型变体：`node-tank` / `node-power` 变种

## 5. 完成标准（Definition of Done）

- [ ] KiCad 原理图 + PCB 入库，**DRC/ERC 无致命错误**
- [ ] 导出 Gerber + 原理图 PDF + BOM（CSV）
- [ ] README 补上：**引脚映射表**（板上每个接口 ↔ 接口契约的 GX 针脚）
- [ ] 原理图体现：续流二极管、保险、防反接、栅极下拉（安全项）
- [ ] （加分）用实验室那套元件打样焊一块，**bring-up 测试**（上电、5V 正常、驱动一路负载、I²C 扫到器件），记录到 README，寄 2–3 片到广州
- [ ] 发 PR 到 `main`，通过接口契约 review

## 6. 自由扩展区 ⭐（鼓励你玩）

**这块板是你的，边界之内随便创新。** 一些可以自我扩展的方向：

- **选型与布局全自由**：DC-DC 芯片、MOSFET、连接器类型、板子尺寸——你说了算。
- **加功能**：每路电流采样、更强的驱动、可寻址状态灯、扩展接口、看门狗电路。
- **做成"节点家族"**：一个通用底板 + 若干变体（鱼缸/供电/种植各一版）。
- **提改进**：如果你觉得接口契约有更好的设计（比如换连接器、加一条总线），**写一条 [ADR](../../../docs/decisions/) 提案**，我们一起拍板——欢迎挑战现有约定。
- **配套**：想加 3D 打印外壳/支架，跟机械那边（P1S）对一下接口即可。

> 目标不是"照图施工"，是给你一块**能长期演进的核心板**去打磨。

## 7. 工作流（异步、低打扰）

- 开分支 `hw/node-baseboard`，改动只在本目录 + 必要的 `docs/decisions/`。
- 提交用 Conventional Commits：`hw(baseboard): add 12V input protection`。
- 完成一部分就发 PR，我按接口契约粗审即可，**不用日常同步**。
- KiCad 自动备份/缓存别提交（已在 `.gitignore`）。

## 8. 上手清单

1. 装 **KiCad**（免费开源）。
2. 打样用 **嘉立创/JLCPCB**（可选 SMT 贴片）。
3. 硬件：实验室那套元件会寄一套到福州给你自测。
4. 读第 2 节的接口契约 → 画原理图 → 布 PCB → 打样 → bring-up。

有问题在对应 **Issue** 里留言即可，异步沟通。放手做，边界我们已经替你定好了。
