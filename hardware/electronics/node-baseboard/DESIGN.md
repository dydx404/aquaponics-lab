## 2. 电源部分

### 2.1 12V 输入保护（安全门禁：保险 + 防反接 + TVS）

```
12V_IN ──[F1 保险丝 5A]──┬──[Q1 P-MOS 防反接]──┬──[D1 TVS]── 12V_BUS
                          │                      │
                         R1 10k                 R2 100k
                          │                      │
                         GND               Gate of Q1
```

| 位号 | 器件 | 型号 | LCSC | 值/参数 | 说明 |
|------|------|------|------|---------|------|
| F1 | 保险丝座 + 5A 保险 | 5×20mm 玻璃管 | C70066741 | 5A / 250V | 过流保护 |
| Q1 | P-MOS 防反接 | AO4407A | C14308 | -30V/-12A, Rds(on)=8mΩ | Vds=-30V 耐 12V 输入 |
| R1 | Q1 栅极下拉 | 0805 电阻 | C17414 | 10kΩ | 确保 MOS 默认关断 |
| R2 | Q1 栅极分压 | 0805 电阻 | C17414 | 100kΩ | 限制栅极充电电流 |
| D1 | TVS 二极管 | SMBJ15A | C110050 | V_RWM=15V, V_BR=16.7V | 钳制 12V 线瞬态 |
| D2 | 稳压二极管 | 1N4744A | C84361 | 15V 0.5W | 保护 Q1 栅源极（Vgs 限压） |

**防反接原理** (v2, 审核 R-3 修正): P-MOS 的 **Drain 接输入正极, Source 接负载侧**, Gate 经 R1(10k) 下拉到 GND。AO4407A 体二极管方向 D→S, 故 Drain 在输入侧时:
- 正接时: Drain=+12V, Source 初始 0V → 体二极管正偏导通 → Source 升到 ~11.3V → V_GS = 0-11.3 = -11.3V < V_GS(th)(-2V) → MOS 导通, 压降极低 (I²R ≈ 0.1V@5A)
- 反接时: Drain=-12V, Source=0V → 体二极管反偏截止 → MOS 保持关断, 负载侧断开, D2 钳位保护栅极
- ⚠️ 若 Source 接输入侧、Drain 接负载侧(初版写法), 反接时体二极管正偏导通 → 保护形同虚设

### 2.3 LDO 5V → 3.3V（传感轨, 独立于 DevKitC 内部 LDO）

> ⚠️ **审核 R-1 修正**: DevKitC 自带 AMS1117-3.3, 板上 U2 也是 AMS1117-3.3。两个稳压器不能并接在同一条 3.3V 网上 (互相倒灌)。
> **方案**: 只给 DevKitC 灌 VIN=5V (pin 18), **不接 DevKitC 的 3V3 pin (pin 1/19 标 NC)**。板上 U2 的 3.3V 输出仅供传感轨 (I²C 上拉 / 1-Wire 上拉 / 数字输入上拉 / BME280 / MCP23017 / ADS1115 / INA226)。两条 3.3V 共 GND 但不共 VCC, 电平相近 (~3.3V) 可靠通信。

## 6. 数字输入调理（6 路）

### 6.1 干接点输入 (CH1, CH4, CH5, CH6) — 3.3V 电平

每路电路:
```
3.3V ── R_pull(10k) ──┬── R_series(1k) ── GPIO_IN
                       │
                     C_filter(100nF)
                       │
                      GND

端子 ── 干接点 ── GND  (接通时拉低, 断开时上拉为高)

保护: BAT54S 钳位 (GPIO 脚 → 3.3V 和 GND)
```

### 6.2 5V 脉冲输入 (CH2, CH3) — 经电平转换

每路电路:
```
5V ── R_pull5V(10k) ──┬── BSS138 Drain
                       │                ┌── R_series(1k) ── GPIO_IN (3.3V)
3.3V ── R_pull3V3(10k)─┘   BSS138 Gate  │
                              BSS138 Src  │
                                         C_filter(100nF)
                              │            │
                          5V signal       GND
```

> **超声波 (审核 R-5)**: CH3 (GPIO35) 是 Echo 输入。**Trig 输出 = GPIO5** (strapping 脚, 无下拉, boot 时内部上拉保 HIGH → 安全)。Trig 为 3.3V 输出, 可直连 JSN-SR04T Trig (3.3V 可触发)。
> **YF-S201 流量 (CH2, GPIO34)**: 纯脉冲输入, 无需 Trig。

### 6.3 器件清单 (每路)

| 位号 | 器件 | 型号 | LCSC | 值 | 用量 |
|------|------|------|------|-----|------|
| R_pull | 上拉电阻 | 0805 | C17414 | 10kΩ | 6 |
| R_series | 限流电阻 | 0805 | C17415 | 1kΩ | 6 |
| C_filter | RC 滤波 | 0805 | C1525 | 100nF | 6 |
| D_clamp | 钳位二极管 | BAT54S | C11723 | 双肖特基 | 6 |
| Q_lvl (CH2/3) | 电平转换 MOS | BSS138 | C528292 | N-MOS SOT-23 | 2 |
| R_pull5V (CH2/3) | 5V 侧上拉 | 0805 | C17414 | 10kΩ | 2 |
| J_DIN | 端子排 2P | KF128-2P | C395882 | 2.54mm 2P | 6 |

> **CH1 = GPIO13 (低水位浮球)**: 符合附录 21.1。GPIO13 有内部上拉, 但仍加外部上拉 + RC + 钳位 (湿区防浪涌)。

## 7. MOSFET 输出（4 路低边开关）

每路电路:
```
12V ──┬── 端子+ (负载正极)
      │
     [负载]
      │
      ├── 端子- (负载负极) ── DRAIN
      │                      MOSFET (IRLZ44N)
     D_flyback              GATE ── R_gate(100Ω) ── GPIO
      │                     SOURCE ── GND
      └── 并联在负载两端    R_pulldown(10kΩ) GATE→GND

状态 LED: 12V ── R_led(1k) ── LED ── DRAIN (负载导通时亮)
```

| 位号 | 器件 | 型号 | LCSC | 值/参数 | 用量 |
|------|------|------|------|---------|------|
| Q_mos | 逻辑 MOSFET | IRLZ44N | C8337 | N-ch, 55V/47A, Vgs(th)=2V | 4 |
| D_fly | 续流二极管 | 1N5819 | C908267 | Schottky 40V/1A | 4 |
| R_gate | 栅极限流 | 0805 | C17563 | 100Ω | 4 |
| R_pd | 栅极下拉 | 0805 | C17414 | 10kΩ | 4 (安全门禁: 必须有) |
| D_mos | 状态 LED | 0805 LED | C84263 | 红色 | 4 |
| R_mosled | LED 限流 | 0805 | C2110 | 1kΩ | 4 |
| J_MOS | 端子排 2P | KF128-2P | C395882 | 2.54mm 2P | 4 |

> ⚠️ **安全门禁**: 每路 MOSFET 必带续流二极管 + 栅极下拉。下拉确保 GPIO 浮空时 MOSFET 截止。

## 14. 泵控制输出（PUMP_STOP, 光耦隔离）

### 安全要求 (ADR-0009):
- **光耦隔离 + 高有效** (禁止低有效: 上电浮空→误吸合→泵自启)
- **NO/NC 跳线, 交付默认 = NO (泵默认关)** (R-1)
- **网络名 = PUMP_STOP** (R-3): 高电平 = 停泵, NC 默认通
- **220V 不上板**: 只出隔离控制信号
- **高水位浮球断控制回路, 不串 220V** (R-2)

### 电路:
```
GPIO27 ── R_led(330Ω) ── PC817 LED+ ── LED- ── GND
                              │
                         PC817 光耦
                              │
                    隔离输出侧:
           3.3V/5V (跳线) ── R_pull(10kΩ) ──┬── COM 端子
                                               │
                                          PC817 C
                                               │
                                          PC817 E ── GND_ISO
                                               │
                                          NO 端子 / NC 端子
```

| 位号 | 器件 | 型号 | LCSC | 值 | 说明 |
|------|------|------|------|-----|------|
| U_OPTO | 光耦 | PC817 | C66580 | 4pin DIP | 电气隔离 |
| R_led | LED 限流 | 0805 | C17168 | 330Ω | I_LED = (3.3-1.2)/330 = 6.4mA |
| R_pull | 输出上拉 | 0805 | C17414 | 10kΩ | 默认态确定 |
| R_pd_pump | GPIO27 下拉 | 0805 | C17414 | 10kΩ | 审核 R-6: boot/复位期间光耦 LED 确保关 (高有效双保险) |
| JP_VCC | 电压跳线 | 排针 3P | — | — | 3.3V / 5V 选择 |
| JP_NCNO | NO/NC 跳线 | 排针 3P | — | — | 默认插 NO (泵关) |
| J_PUMP | 端子排 3P | KF128-3P | C395882 | 2.54mm | COM/NO/NC |

> ⚠️ **PUMP_STOP 高有效**: GPIO27 = HIGH → 光耦导通 → 输出有效 → 停泵。
> 上电时 GPIO 浮空 → 光耦不导通 → 输出无效 → 泵不受控 (NO=断=泵关, 满足交付默认 OFF)。

## 15. 高水位浮球安全回路（独立于 MCU）

### 安全要求 (ADR-0009 R-2):
- 高水位浮球 NC 触点串继电器线圈/光耦输入 (低压)
- **严禁串 220V** (浮球额定 0-110V, 拉弧→熔焊→失效/起火)
- 独立于 MCU (硬件安全, 不经软件)

### 电路:
```
12V ── R_hw(1kΩ) ──┬── PC817-2 LED+ ── LED- ── 高水位浮球NC ── GND
                    │
                高水位浮球正常(未触发): NC 通 → 光耦导通 → PUMP_STOP 回路允许
                高水位触发: NC 断 → 光耦截止 → PUMP_STOP 回路强制断开(停泵)
```

> 此光耦串联在 PUMP_STOP 信号路径上, 高水位触发时强制断开泵控制回路, 不经 MCU。
> 使用独立光耦 PC817 (U_OPTO2), 与 MCU 侧 PUMP_STOP 光耦级联。

| U_OPTO2 | 安全光耦 | PC817 | C66580 | 高水位断泵 |
| R_hw | 限流 | 0805 C17168 | 1kΩ | I = (12-1.2)/1k = 10.8mA |
| J_HW | 端子排 2P | KF128-2P | C395882 | 高水位浮球接入 |

## 18. PCB 设计约束

- **2 层板**: Top 层走信号 + 元件, Bottom 层走地 + 部分信号
- **铺铜**: 底层整板 GND 铺铜, 顶层在空闲区域铺铜
- **电源走线**: 12V/5V 主电路线宽 ≥ 30mil (0.76mm), 3.3V ≥ 15mil
- **大电流**: INA226 分流电阻路径、MOSFET 负载路径线宽 ≥ 40mil
- **安装孔**: 4× M3 (φ3.2mm), 位于板角, 距边 5mm
- **丝印**: 标全接口名/极性/引脚号/失电默认态 (PUMP_STOP: "高=停泵, 默认NO=关")
- **板尺寸**: 目标 ≤ 100×80mm (嘉立创 5 片 ¥2 优惠尺寸)
- **DRC**: 2 层, 最小线宽 6mil, 最小间距 6mil, 最小过孔 0.3/0.5mm
