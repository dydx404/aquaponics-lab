# hardware · 3D 打印件

用 Bambu Lab P1S 打印。**源文件放 `src/`，导出的 STL 放 `stl/`。**

## 规划中的零件

- 传感器航插座 / 探头固定座
- 缸口溢流 / 背挂溢流件
- 螺旋喂食器（配舵机/步进）
- 陀螺体(gyroid)生化填料
- 货架卡扣 / 管路固定卡
- 控制面板 / 铭牌

## 约定

- 命名：`<part>-<rev>.<ext>`，如 `overflow-hangon-a.step`。
- 材料标注：PETG（耐候）/ TPU（密封）/ PLA（非受力）。
- 每个零件在 `src/` 附一句用途 + 打印参数（层高/填充/支撑）。
