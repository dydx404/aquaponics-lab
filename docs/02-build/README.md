# 02 · 施工指南 Build Guide（按 MVP）

按顺序推进，**每个 MVP 有明确验收标准**；未过关不进下一步——尤其放鱼、长时间放水前不跳步。

## MVP-0 · 场地与图纸 ✅

- [x] 量转角尺寸、确认朝向（东南）、排水（可放地板→地漏）、插座。
- [x] 定货架尺寸 100×50×118、定"重物落地"布局。

## MVP-1 · 骨架

- [ ] 角钢货架在转角立稳、不晃、不挡门。
- [ ] 空玻璃缸/桶在地面与层板试摆，落位确认。
- **验收**：架子稳固、空缸就位、通道顺畅。

## MVP-2 · 水路闭环（先干后湿）

- [ ] 塑料桶开孔装接头（平壁水箱接头 / 圆桶 Uniseal）。
- [ ] 接通 集水桶→泵→供水总管→各缸→回水总管→集水桶。
- [ ] 断泵实测：集水桶接得住回流、不外溢。
- **验收**：连续循环 **24h 零漏水**，溢流可引地漏。

## MVP-3 · 溢流 / 钟形虹吸

- [ ] 各缸竖管定水位稳定；（如用介质床）虹吸淹排周期正常。
- **验收**：稳定循环 24h，无溢顶、无抽干。

## MVP-4 · 首个 ESP32 节点（`node-tank01`）

- [ ] 水温（DS18B20）+ 水位 + 泵电流/流量 上 Home Assistant。
- [ ] 断泵 / 缺水 → 手机告警。
- **验收**：HA 仪表盘实时出数；拔泵手机响。
- 配置见 [`firmware/esphome/node-tank01.yaml`](../../firmware/esphome/node-tank01.yaml)。

## MVP-5 · 养菌开缸

- [ ] 无鱼跑氮循环（加氨源喂菌），2–4 周。
- **验收**：氨=0、亚硝酸盐=0、出现硝酸盐。见 [运维/养菌](../04-operations/cycling.md)。

## MVP-6 · 放鱼

- [ ] 引入叉尾斗鱼 + 樱花虾，少量起步。
- **验收**：稳定运行 1 周，水质正常，鱼状态好。

## 之后（Phase 3+）

自动化（喂食/灯/降温/加药）→ 太阳能离网 + 能量调度 → 视觉/AI（认鱼、日报）→ 闭合物质循环（黑水虻、浮萍）。
