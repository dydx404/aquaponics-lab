# 00 · 系统总览 System Overview

> 一句话：把鱼菜共生当作一个**开源版家庭 SCADA**——鱼和菜是"负载"，真正的主体是可持续迭代的**监控 + 控制 + 数据**系统。

## 设计哲学（三条铁律）

1. **物理失效安全优先** — 绝不让"电子系统正常"成为鱼存活的前提。断电、断网、泵坏，靠重力与结构也要撑住数小时。
2. **一切可热插拔** — 机械上统一角钢 + 3D 打印卡扣；电气上统一航空插头；软件上统一 MQTT 命名。加模块 = 插上即用。
3. **数据即乐趣** — 氮循环、水质、能量、鱼行为都变成可观测、可回放的数据流。

## 场景与约束

- 地点：广州，东南朝向小阳台（上午到中午直射、避开西晒，夏季控温相对有利）。
- 供电：12V DC 母线 + 太阳能（~20–30W 板 + PWM 控制器）+ 12V 电池；关键负载可市电兜底。
- 结构：碳钢角钢货架 **100(长) × 50(宽) × 118(高) 四层**，单层承重仅 ~35–40kg（**弱层板**，见 ADR-0003）。

## 核心架构：CHOP2 单泵闭环

全系统只有一个水泵，其余全靠重力（见 [ADR-0001](decisions/0001-chop2-single-pump.md)）。

```
集水/生化桶(单泵，落地)
        │ 泵上顶
        ▼
   供水总管(每口缸一个球阀分支)
        │
        ▼
   多口小玻璃缸(缸口/竖管定水位、溢流)   ← 见 ADR-0002
        │ 溢流
        ▼
   底部回水总管 ──► 回集水/生化桶  ↺
```

- 生物过滤：物理棉（拦固体）→ 生化滤材（硝化细菌：氨 → 亚硝酸盐 → 硝酸盐）。
- 鱼：叉尾斗鱼（本土、耐热、有迷鳃）+ 樱花虾清洁队。

## 软硬件栈

| 层 | 用什么 | 作用 |
|---|---|---|
| L0 物理 | 虹吸、溢流、集水桶兜底 | 零电力失效安全 |
| L1 节点 | ESP32 + ESPHome | 各模块传感/执行，发 MQTT |
| L2 中枢 | 树莓派 + Home Assistant + MQTT | 跨模块自动化、告警、仪表盘 |
| L3 数据 | InfluxDB + Grafana、Frigate | 长期记录、视觉 |
| L4 智能 | CV / LLM 日报 | 鱼行为、自动总结 |
