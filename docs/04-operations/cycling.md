# 04 · 养菌开缸 Fishless Cycling

开缸的本质是**养出硝化细菌**，把鱼产生的剧毒氨转化掉。急不得，通常 2–4 周。

## 步骤

1. 装好滤材（物理棉在前、生化滤材在后），通水循环空跑。
2. **加氨源喂菌**：丢一点鱼食任其腐烂，或滴加氨水，制造氨。
3. 每 2–3 天测一次水（氨 / 亚硝酸盐 / 硝酸盐）。
4. 观察曲线：氨↗ 然后↘，亚硝酸盐↗ 然后↘，硝酸盐持续↗。
5. **达标**：氨 = 0、亚硝酸盐 = 0、出现硝酸盐 → 细菌成军，可少量放鱼。

## 氮循环

```
鱼/残饵 → 氨(NH3/NH4+，剧毒)
        → 亚硝酸盐(NO2-，仍毒)     [亚硝化菌]
        → 硝酸盐(NO3-，低毒)        [硝化菌]
        → 被植物吸收 / 换水移除
```

## 保养禁忌

- 物理棉勤洗，**只用旧缸水**冲。
- 生化滤材**几乎不洗**，**绝不用自来水**（余氯杀菌，一夜白养）。
- 不要 100% 换水、不要过度清洗——会把菌群清空。

用传感器 + Grafana 把上面这条氮循环曲线**画出来、存下来**——这是系统第一个"科学时刻"。
