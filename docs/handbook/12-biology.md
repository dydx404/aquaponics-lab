## 12.1 鱼菜共生原理 🔬

鱼菜共生(aquaponics)是**水产养殖 + 无土栽培**的闭环：

```
鱼 → 产生含氨废物 → 硝化细菌转化为硝酸盐 → 植物吸收(净化水) → 干净水回到鱼
```

三个生物主体：**鱼**（产肥）、**微生物**（转化）、**植物**（吸收净化）。三者平衡是系统稳定的核心。

## 12.2 氮循环（系统的心脏）⭐🔬

鱼的氨对鱼有剧毒，靠硝化细菌逐级转化：

$$ \text{有机废物/鱼} \to NH_3/NH_4^+ \xrightarrow{\text{亚硝化菌}} NO_2^- \xrightarrow{\text{硝化菌}} NO_3^- $$

- **氨 NH₃**：剧毒，pH 越高越毒（游离氨占比升高）。
- **亚硝酸盐 NO₂⁻**：仍有毒。
- **硝酸盐 NO₃⁻**：低毒，被植物吸收或换水移除。

**开缸(cycling)** 就是养出这套菌群，通常 2–4 周（见 [docs/04-operations/cycling](../04-operations/cycling.md)）。达标标志：氨=0、亚硝酸盐=0、出现硝酸盐。

## 12.3 关键水质参数与相互关系 🔬

| 参数 | 理想范围（斗鱼/综合） | 说明 |
|---|---|---|
| 水温 | 20–28°C（斗鱼耐热更宽） | 高温 → 溶氧降、代谢/毒性升 |
| 溶氧 DO | > 5 mg/L | 高温最危险；斗鱼有迷鳃可补呼吸 |
| pH | 6.8–7.4（折中） | 影响氨毒性与硝化效率、养分可利用性 |
| 氨/亚硝酸盐 | ≈ 0 | 任何可测值都需警惕 |
| 硝酸盐 | 适量（植物吃） | 过高则需换水/加种植 |
| EC | 视植物 | 养分总量代理 |

⚠️ **耦合关系（自动化要懂）**：温度↑ → DO↓ 且氨毒性↑，这是夏季高温同时踩两个雷，所以"高温降温级联"要同时**降温 + 增氧**。

## 12.4 生物选择

### 12.4.1 鱼：叉尾斗鱼（中国斗鱼）⭐

- 广东**本土**、颜色艳丽、极耐折腾。
- **迷鳃器官**可直接呼吸空气 → 耐低氧，夏季缺氧更不易翻缸，非常契合失效安全理念。
- 配樱花虾/黑壳虾做清洁队。

### 12.4.2 植物

- 叶菜（生菜、罗勒、薄荷）易活、吸氮好，放东南受光侧。
- 进阶：浮萍/满江红（超快生长的吸氮 + 补充饲料，闭合物质循环）。

## 12.5 生物过滤与滤材（与第 4 章呼应）

硝化细菌附着在**生化滤材**（K1/细菌屋/gyroid）表面的生物膜上。滤材比表面积越大、水流含氧越好，硝化能力越强。**绝不用自来水冲生化滤材**（余氯灭菌）。

## 12.6 动物福利（伦理底线）⚠️

- 失效安全设计不只是工程，更是**对活体负责**：断电断网也要保命。
- 放鱼前必须完成开缸（否则氨中毒）。
- 密度适中、投喂适量（过量残饵→氨爆表）。
- 高温季主动干预（降温 + 增氧）。

## 12.7 进阶：闭合物质循环（长期愿景）

- **黑水虻(BSFL)**：厨余 → 虫 → 鱼饲料。
- **浮萍/满江红**：吸营养 + 补饲料。
- 目标：让"投入"越来越少来自外部，系统越来越像一个自洽生态。
