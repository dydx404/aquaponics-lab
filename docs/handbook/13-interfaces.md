# 第 13 章 · 接口契约 Interface Contracts ⭐

> 稳定（改动需 ADR + 双方确认）。**这是全书最重要的一章**：只要接口契约稳定，两个人就能在各自分支上独立开发、互不阻塞，最后一拼就通。

## 13.1 为什么接口契约是并行开发的关键

模块之间只通过**明确定义的接口**耦合。硬件负责人只要保证"我出线的针脚定义、电平、数据主题符合契约"，软件负责人就能在不看硬件实现的情况下写好对接。**改接口 = 改公共契约 = 必须 ADR + 通知对方**；改模块内部实现则自由。

接口分四类：**电气、机械、软件、数据**。

## 13.2 电气接口 ⚡

### 13.2.1 电源分域（v2）⚡

**两个物理隔离的供电域**（见 [ADR-0004](../decisions/0004-power-domains.md)）：

| 域 | 电压 | 供给 | 安全 |
|---|---|---|---|
| **市电域** | 220V AC | 主循环泵（及打氧等大功率负载） | **必须漏电保护(RCD)** + 滴水弯 |
| **控制/电子域** | 12V DC（太阳能+电池）→ 5V → 3.3V | ESP32、树莓派、传感器、12V 轻载(阀/风扇/灯) | 低压、水边优先 |

- 12V 域色标：红=+12V，黑=GND；逻辑 **3.3V**（5V 器件需电平转换）。
- 每支路独立保险；控制域内共地(GND)、星形接地；**AC 与 DC 两域电气隔离、分区走线**。
- 泵等大功率负载**不接 12V、不上节点板**：走市电经继电器/固态继电器，由节点弱电控制信号触发。

### 13.2.2 连接器：分两层（v2，方案已定 → 见 [functional-spec](../functional-spec.md)）

契约拆成**电气层（冻结）**与**物理连接器层（延后）**（见 [ADR-0005](../decisions/0005-connector-layer-deferred.md)）。原因：连接器一部分由传感器本身决定，**航插不适用于一切**（pH 探头天生 BNC、I²C 模块是排针/JST、DS18B20 是三线成品、有些探头固定线长），且不同信号的**布线长度**约束天差地别。

- **电气层（现在冻结，与具体传感器无关）**：供电轨、逻辑 3.3V、总线类型（I²C / 1-Wire / 模拟经 ADS1115 / 脉冲）、上拉、续流二极管、MQTT 主题。
- **物理连接器层（先别冻）**：等真传感器到手，按其原生接口与线长逐个定；**航插只用在"要防水/可插拔/户外"的场合**。PCB 一律做**连接器无关**：总线引到通用排针/端子，再用转接线接各传感器。

**布线长度规则**（决定"传感器放多远"）：

| 接口 | 距离能力 | 原生连接器 | 原则 |
|---|---|---|---|
| I²C（BME280/BH1750/ADS1115/INA226/RTC） | 短，≤~0.5–1m | 排针/JST | 传感器**靠近节点** |
| 1-Wire（DS18B20） | 可几米 | 3 线/防水头 | 适合远端温度 |
| 模拟高阻（pH/ORP） | 探头信号极易衰减 | **BNC** + 模块 | **放大器贴探头**，只把处理后信号拉远 |
| 称重（应变片） | 电桥 μV | — | **HX711 贴近应变片** |
| 脉冲（流量） | 中等 | 3 线 | 还好 |
| 12V 负载（阀/风扇/灯） | 可较长 | 端子 / GX | 防水可插拔用 GX |

> **架构结论**：节点（含 ADC/放大器）**靠近传感器、短线**，只让稳健/数字信号跨距离——这正是"一模块一节点"的理由。

### 13.2.3 I²C 地址分配

多器件共总线靠地址区分，维护唯一地址表（见 [第 21 章附录](21-appendix-pinouts.md)）。新增器件先查表、防冲突。

### 13.2.4 信号约定

- 数字输入默认上拉、低有效需注明。
- 模拟量注明量程与对应物理范围。
- 感性负载驱动**必须含续流二极管**（硬件契约，见 [第 8 章](08-actuators.md)）。

## 13.3 机械接口 📐

| 项 | 规范 |
|---|---|
| 安装基准 | 传感/执行装于 3D 打印底座，卡扣统一卡角钢/管路 |
| 打印公差 | 配合孔 +0.2~0.4 mm；螺纹用热熔螺母 M3 |
| 管路 | 主管 25 mm；排水/溢流 32–40 mm；快接/球阀便于拆装 |
| 开孔 | 塑料平壁=水箱接头；圆桶=Uniseal（尺寸表见附录）|
| 玻璃缸 | **不钻孔**，缸口/背挂溢流 |
| 承重 | 缸长 ≤40 cm 上层板；≥50 cm 落地；放水层板垫木板 |

## 13.4 软件接口 💻

### 13.4.1 MQTT 主题模式 ⭐

**统一命名空间**：

```
aqua/<node>/<metric>
```

- `<node>`：`tank01` / `power` / `grow` / `vision` …（不含 `node-` 前缀，前缀在设备名里）。
- `<metric>`：`water_temp` / `water_level` / `pump_current` / `battery_v` …（snake_case）。
- 命令主题：`aqua/<node>/<actuator>/set`。
- 执行器状态回读：`aqua/<node>/<actuator>/state`（ON/OFF，执行器实际状态）。
- 状态/遗嘱：`aqua/<node>/status`（online/offline，用 LWT）。

示例：
```
aqua/tank01/water_temp      27.4
aqua/tank01/low_water       ON
aqua/power/battery_v        12.6
aqua/grow/light/set         ON
```

### 13.4.2 命名与配置约定

- 节点设备名：`node-<function><index>`。
- 文件/目录：kebab-case。
- 密钥：一律 `!secret`；`secrets.yaml` 进 `.gitignore`（公开仓库红线）。

## 13.5 数据接口（单位与量程）📊

统一单位与量程，避免"你以为 mV 我以为 V"这类事故：

| 量 | 单位 | 合理范围 | 备注 |
|---|---|---|---|
| 水温 | °C | 0–40 | 超范围判故障 |
| pH | — | 0–14（常用 5–9） | 需温补/标定 |
| EC | µS/cm 或 mS/cm | 视植物 | 温补到 25°C |
| DO | mg/L | 0–15 | 温度/盐度补偿 |
| ORP | mV | −500~+800 | — |
| 浊度 | NTU | 0–1000 | — |
| 水位 | cm 或 % | 0–缸高 | 另有浮球布尔兜底 |
| 流量 | L/min | 0–20 | 脉冲换算 |
| 电流 | A | 视支路 | INA/ACS |
| 电压 | V | 0–15（12V 系统） | — |

## 13.6 接口变更流程 ⚠️

1. 提出变更 → 开 Issue。
2. 写/更新 **ADR**（[docs/decisions](../decisions/)）说明原因与影响。
3. **双方（硬件 + 软件）确认**。
4. 同步更新本章与 [第 21 章附录](21-appendix-pinouts.md)。
5. 相关分支据新契约调整。

> 口诀：**内部实现随便改，公共接口要开会。**
