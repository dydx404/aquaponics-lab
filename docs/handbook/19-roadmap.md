# 第 19 章 · 路线图与里程碑

> 演进中。施工细节在 [docs/02-build](../02-build/)；本章给全局节奏与模块映射。

## 19.1 MVP 里程碑

| MVP | 目标 | 主责模块 | 验收 |
|---|---|---|---|
| MVP-0 | 场地与图纸 ✅ | M1/M2 | 尺寸/朝向/排水/布局已定 |
| MVP-1 | 骨架 | M2 | 货架立稳、空缸就位 |
| MVP-2 | 水路闭环 | M1 | 连跑 24h 零漏水 |
| MVP-3 | 溢流/虹吸 | M1 | 稳定循环 24h |
| MVP-4 | 首个 ESP32 节点 | M4/M6/M7 | 水温+水位+泵流上 HA、断泵告警 |
| MVP-5 | 养菌开缸 | M10 | 氨/亚硝酸归零、出现硝酸盐 |
| MVP-6 | 放鱼 | M10 | 稳定 1 周 |

## 19.2 阶段路线（MVP 之后）

- **Phase 3 · 自动化**：喂食、灯光、降温级联、pH 加药、失效告警全套。（M5/M7）
- **Phase 4 · 离网 + 硬化**：太阳能优先调度、能量面板、冗余/看门狗、天气联动。（M3/M7）
- **Phase 5 · 智能 + 闭环**：CV 认鱼/行为、LLM 日报、数字孪生；黑水虻/浮萍闭合物质循环。（M9/M10）

## 19.3 版本规划（示意）

- `v0.1` 仓库 + 手册骨架（当前）。
- `v0.2` MVP-1~3 完成（机械 + 水路）。
- `v0.3` MVP-4 首节点 + HA 告警。
- `v0.4` MVP-5~6 生物上线。
- `v0.5` Phase 3 自动化。
- `v1.0` 稳定运行 + demo 展示级 + 可复刻文档齐全。
