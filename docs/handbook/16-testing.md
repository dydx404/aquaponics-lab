# 第 16 章 · 测试、调试与验收

> 演进中。每个 MVP 有明确验收标准；未过关不进下一步（尤其放鱼/长时间放水前）。

## 16.1 测试层级

| 层级 | 对象 | 方法 |
|---|---|---|
| 元件级 | 单个传感/执行 | 台面通电、读数/动作核对 |
| 节点级 | 单个 ESP32 节点 | 固件烧录、MQTT 出数、执行动作 |
| 子系统级 | 水路 / 供电 | 干跑/湿跑、负载测试 |
| 系统级 | 全链路 | 端到端：传感→中枢→执行→告警 |
| 长期 | 稳定性 | 24h/周级 soak 测试 |

## 16.2 各 MVP 验收标准（对应 [第 19 章](19-roadmap.md)）

- **MVP-1 骨架**：货架立稳不晃、空缸就位、通道顺畅。
- **MVP-2 水路**：连续循环 **24h 零漏水**；断泵实测集水桶接得住回流。
- **MVP-3 溢流/虹吸**：稳定循环 24h，无溢顶/抽干；虹吸周期正常。
- **MVP-4 首节点**：水温/水位/泵流上 HA；**拔泵手机响**。
- **MVP-5 养菌**：氨=0、亚硝酸盐=0、出现硝酸盐。
- **MVP-6 放鱼**：稳定运行 1 周，水质正常，鱼状态好。

## 16.3 关键调试技巧 🔧

- **电气**：先空载测电压/极性再上负载；用限流台式电源保护；万用表/逻辑分析仪查 I²C/信号。
- **I²C**：`scan` 确认地址；线太长/无上拉会失联。
- **传感器**：先对已知参照物标定（冰水 0°C、标准 pH 液）。
- **MQTT**：用 `mosquitto_sub -t 'aqua/#' -v` 看全量消息流。
- **水路**：先**干跑**（清水循环）找漏点，再进生物。
- **感性负载**：确认续流二极管在位再驱动，防烧管。

## 16.4 预测性维护信号 ⭐

- 泵电流上升 / 流量下降 → 滤材或管路堵塞。
- 虹吸周期变长 → 介质床将堵。
- DO 持续下降 / 夜间骤降 → 生物负载过高或增氧不足。
把这些设成 Grafana 面板 + HA 告警。

## 16.5 回归与复现

- 配置改动后跑一遍对应层级测试。
- 关键实验数据导出入 `data/`，便于复刻者对照"已知良好(known-good)"。
