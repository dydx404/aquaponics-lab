# 第 17 章 · 运维与维护

> 演进中。系统跑起来之后，怎么让它长期健康。详见 [docs/04-operations](../04-operations/)。

## 17.1 日常 / 周期维护表

| 周期 | 事项 |
|---|---|
| 每日（自动+扫一眼） | 看仪表盘：水温/DO/泵流/告警；喂食（自动）；观察鱼状态 |
| 每周 | 测水质（氨/亚硝酸盐/硝酸盐/pH）；洗物理棉（旧缸水）；清理残饵 |
| 每两周 | 部分换水（视硝酸盐）；旋流排污；检查管路/接头 |
| 每月 | 检查泵/风扇/电池；标定电极复查；清理藻类 |
| 每季 | 电极标定/更换；紧固结构；固件/HA 更新与备份 |

## 17.2 换水与补水

- 有地漏：集水桶底球阀 → 软管引地漏，换水=拧阀。
- 自动补水（可选）：低水位 → 电磁阀补水，**带超时保护**防溢。
- 换水用**除氯水**（晾置/除氯），避免杀菌。

## 17.3 滤材保养（复述红线）⚠️

- 物理棉勤洗，**只用旧缸水**。
- 生化滤材**几乎不洗、绝不用自来水**（余氯灭菌）。
- 不做 100% 换水/大清洗，保护菌群。

## 17.4 季节性

- **夏季**：重点控温增氧（降温级联）；防藻；关注 DO 夜间低点。
- **冬季（广州偶有冷潮）**：斗鱼耐低温尚可；必要时加热棒 + 保温。
- **台风/回南天**：结构固定、防水、天气联动提醒。

## 17.5 故障排查速查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 泵不出水 | 堵/气锁/泵坏/断电 | 查电流与流量、排气、清堵 |
| 缸水位异常 | 溢流堵/倒虹吸 | 清溢流、检查防虹吸孔 |
| 鱼浮头 | 缺氧/高温 | 立即增氧+降温，查 DO |
| 氨/亚硝酸升高 | 菌群不足/过量投喂/滤材堵 | 减投喂、换水、查滤材 |
| 节点离线 | WiFi/供电 | 查供电、信号、看门狗日志 |
