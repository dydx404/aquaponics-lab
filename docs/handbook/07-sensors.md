# 第 7 章 · 传感器与测量原理（M4）

> 演进中。负责人：硬件(EE)。本章是全书电子原理最密集的一章。

## 7.1 职责与边界

- **职责**：把物理/化学量转成可靠的数字信号上报。
- **关注**：测量原理、信号调理、隔离、标定、误差。
- **接口**：总线（1-Wire/I²C/模拟）、供电电平、数据单位与量程（见 [第 13 章](13-interfaces.md)）。

## 7.2 测量链与关键概念 🔬

一条完整测量链：

```
被测量 → 传感器(换能) → 信号调理(放大/滤波/隔离) → ADC(量化) → MCU → 标定/滤波 → 上报
```

- **分辨率**：ADC 位数决定最小可分辨步长。$n$ 位、量程 $V_{ref}$ 时，LSB = $V_{ref}/2^n$。ESP32 内置 12 位 ADC 但**非线性、噪声大**，测 pH/EC 这类小信号务必外置 **ADS1115（16 位、可编程增益 PGA、I²C）**。
- **精度 vs 分辨率**：分辨率是"看得多细"，精度是"离真值多近"。高分辨率不等于准，**标定**才决定精度。
- **信噪比/滤波**：水泵、电机是噪声源。用硬件 RC 滤波 + 软件滑动平均/中值滤波压噪；传感器线远离电源线。
- **接地与隔离**：pH/EC 电极对地环流敏感，常需**隔离模块**（见 7.4）。

## 7.3 温度：DS18B20（1-Wire）🔬

- **原理**：数字温度传感器，内部带 ADC，输出数字温度；总线协议 **1-Wire**（单线 + 地），每颗有唯一 64 位地址，**一条总线挂多颗**。
- **接线**：数据线加 4.7 kΩ 上拉到 3.3V；防水版直接入缸。
- **用途**：每口缸一颗测水温（夏季控温关键）；环境温度另用 BME280/SHT31。
- **要点**：多颗时先扫描地址并在配置中固定，避免顺序漂移。

## 7.4 水质电极：电化学测量 🔬（难点）

pH、ORP、DO、EC 都是**电化学/电学传感**，共同难点：高阻抗、易受干扰、需标定、会老化。

### 7.4.1 pH（酸碱度）

- **原理（能斯特方程）** 📐：玻璃电极产生的电位与氢离子活度成对数关系：
  $$ E = E_0 - \frac{2.303\,RT}{F}\,\text{pH} $$
  25°C 时斜率约 **−59.16 mV/pH**。即每变化 1 个 pH，电位变约 59 mV。
- **高阻抗**：pH 电极内阻可达 10⁸ Ω，信号极弱，必须用**高输入阻抗放大 + 隔离采集模块**（如 pH4502C / 工业隔离板）再进 ADS1115。
- **温度补偿**：斜率含 T，需配温度做 ATC（自动温补）。
- **标定**：用 pH 4.00 / 6.86 / 9.18 标准液做两点或三点标定；电极会老化漂移，需定期复标。

### 7.4.2 ORP（氧化还原电位）

- **原理**：铂电极相对参比电极的电位，反映水体氧化/还原倾向（mV）。反映消毒/有机负荷/水质"活性"。
- **调理**：与 pH 类似，高阻抗、需隔离。

### 7.4.3 EC / 电导率（养分浓度代理）

- **原理**：水的导电能力正比于离子浓度。施加**交流**激励（防电极极化），测电导。EC 反映溶解盐/养分总量，是水培营养的关键指标。
- **温度依赖强**：电导随温度显著变化，必须温补到 25°C 标准。
- **TDS**：由 EC 换算的"总溶解固体"，是近似值。

### 7.4.4 DO（溶解氧）⭐ 最贵最关键

- **原理**：两类——
  - **电化学（原电池/极谱）**：透膜的氧在电极被还原产生电流 ∝ 溶氧；需换膜、补电解液。
  - **光学荧光法**：荧光物质被氧猝灭，测荧光寿命/相位反推溶氧；**免维护、更稳**，但贵。
- **重要性**：夏季水温高 → 溶氧低 → 鱼窒息风险最高。DO 是控温/打氧自动化的核心输入。
- **温度/盐度补偿**：溶氧饱和度随温度、盐度变化，需补偿。

### 7.4.5 浊度 Turbidity

- **原理**：光学，测悬浮颗粒对光的散射/透射。反映水清浊、藻类、滤材是否失效。

## 7.5 水位与流量

### 7.5.1 水位（多法互补）🔬

| 方法 | 原理 | 优缺点 |
|---|---|---|
| 浮球开关 | 机械触点 | 极便宜可靠，只有"到/没到"两态 → 做缺水保护/兜底 |
| 超声波(防水 JSN-SR04T) | 测回波时间 → 距离 | 非接触、连续读数；泡沫/水汽有干扰 |
| 投入式压力液位 | 测水柱静压 ∝ 水深 | 工业级、连续、精度好；较贵 |
| 电容/光电 | 介电/折射变化 | 便宜，需标定 |

**策略**：连续量用超声波/投入式，**再叠一个浮球开关做独立的缺水断泵兜底**（冗余，符合失效安全）。

### 7.5.2 流量：YF-S201（霍尔）🔬

- **原理**：水流推动内部叶轮，叶轮上磁体经过霍尔元件产生脉冲，**频率 ∝ 流量**。MCU 计数脉冲换算 L/min。
- **用途**：确认循环在跑；流量下降 = 堵/泵弱 → 告警；配合虹吸周期做预测性维护。

## 7.6 环境与光照

- **BME280 / SHT31（I²C）**：温湿度（+气压）。用于环境监测、夏季热管理、露点。
- **BH1750 / TSL2591（I²C）**：光照度（lux）。用来**实测阳台每天几小时直射**、驱动植物灯补光策略。

## 7.7 称重：HX711 + 应变片 🔬

- **原理**：应变片(load cell)受力变形 → 电阻变化 → 惠斯通电桥输出微弱差分电压 → **HX711（24 位专用 ADC）**放大量化。
- **用途**：喂食定量（按克下料）、按重量间接测水量、监测整缸重量变化。

## 7.8 时间基准：DS3231 RTC

- 高精度实时时钟（带温补晶振 + 纽扣电池）。断网也能保时间，支撑本地定时（喂食、灯）。

## 7.9 I²C 总线管理 ⭐

多个 I²C 器件共用 SDA/SCL，靠**地址**区分。需维护一张**地址分配表**（见 [第 21 章附录](21-appendix-pinouts.md)）避免冲突：
- ADS1115：0x48–0x4B（可选）
- INA219/226：0x40–0x4F（可选）
- BME280：0x76/0x77
- BH1750：0x23/0x5C
- DS3231：0x68

地址冲突时用可选地址脚或 I²C 多路复用器（TCA9548A）。

## 7.10 标定与误差管理（纪律）

- 电化学电极（pH/EC/DO/ORP）**必须定期标定**，并在文档/HA 记录标定日期与偏移。
- 每个传感器在配置中标注：量程、单位、更新周期、滤波、标定参数。
- 数据可信度：给关键量设**合理范围**，超范围判为故障并告警（防"坏值误触发"自动化）。
