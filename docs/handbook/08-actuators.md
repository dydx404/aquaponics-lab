# 第 8 章 · 执行器与驱动电路（M5）

> 演进中。负责人：硬件(EE)。传感是"读"，执行是"写"——本章讲怎么安全地驱动负载。

## 8.1 职责与边界

- **职责**：把控制指令变成物理动作（水、气、光、机械）。
- **关注**：驱动电路、开关方式、感性负载保护、PWM 调制、安全联锁。
- **接口**：控制信号电平、驱动电流/电压、失电默认状态（见 [第 13 章](13-interfaces.md)）。

## 8.2 负载类型与驱动方式总览

| 负载 | 电气特性 | 驱动方式 |
|---|---|---|
| 水泵（DC/AC） | 感性、启动电流大 | 继电器 / MOSFET（DC）/ 交流固态继电器（AC） |
| 电磁阀 | 感性 | MOSFET + 续流二极管 |
| 直流风扇 | 感性、小电流 | MOSFET（可 PWM 调速） |
| LED 灯 | 恒流/恒压 | MOSFET（PWM 调光）或恒流驱动 |
| 舵机 | 内部有驱动 | PWM 信号直驱（供电分开） |
| 步进电机 | 需时序 | 专用驱动（A4988/DRV8825） |
| 蠕动泵 | 直流电机/步进 | MOSFET 或步进驱动 |

## 8.3 开关器件：继电器 vs MOSFET 🔬

### 8.3.1 机械继电器

- **原理**：线圈通电吸合触点，实现**电气隔离**的通断。
- **优点**：能切交流/大电流、天然隔离、直观。
- **缺点**：有寿命（触点电弧磨损）、切换慢、不能 PWM、线圈本身是感性负载（模块通常已含续流二极管与光耦）。
- **用途**：市电 25W 泵、需隔离的大负载。

### 8.3.2 MOSFET（低边开关）🔬

- **原理**：电压控制的开关。**低边驱动**：负载接 12V 正，另一端接 MOSFET 漏极，源极接地，栅极加电压导通。
- **逻辑电平 MOSFET**：ESP32 是 3.3V 逻辑，必须选 **logic-level（如 IRLZ44N）**，保证 $V_{GS}=3.3V$ 时能充分导通；普通 IRF520 在 3.3V 下导通不全、发热，不推荐直驱。
- **导通损耗** 📐：$P = I^2 \cdot R_{DS(on)}$，选低 $R_{DS(on)}$ 器件、必要时加散热。
- **栅极电阻 + 下拉**：栅极串小电阻限 di/dt，栅极对地加下拉电阻（如 10 kΩ）防止上电/复位时误导通。

### 8.3.3 感性负载保护 ⚠️🔬

泵、阀、电机断电瞬间，电感电流不能突变，会产生高压尖峰（$V=-L\frac{di}{dt}$）击穿开关器件。**必须加保护**：

- **续流二极管（flyback diode）**：并联在感性负载两端（反向），给电流回路，钳住尖峰。DC 负载标配。
- **RC / TVS 缓冲（snubber）**：交流或高能量场合。

**这是 EE 常识但极易被业余者忽略——漏掉续流二极管是烧 MOSFET/继电器最常见原因。**

## 8.4 PWM 调制 🔬

- **原理**：用固定频率、可变占空比的方波，等效调节平均功率。占空比 $D$，平均电压 $\approx D \cdot V_{supply}$。
- **用途**：风扇调速、LED 调光、蠕动泵调速。
- **频率选择**：风扇/电机几百 Hz–20 kHz（>20 kHz 避免可闻噪声）；LED 调光注意频闪。ESP32 用 LEDC 硬件 PWM。

## 8.5 电机驱动

### 8.5.1 步进电机（A4988 / DRV8825）🔬

- **原理**：按相位时序逐步转动，**开环高精度定位**。驱动芯片负责电流斩波与细分（microstepping）。
- **参数**：设定电流限（据电机额定）、细分数（精度 vs 平滑）。用于精确喂食、阀门、遮阳。

### 8.5.2 舵机（SG90/MG996）

- 内部含位置闭环，输入 PWM（周期 20 ms，脉宽 1–2 ms 对应角度）。**供电与逻辑分开**，堵转电流大。用于阀门、遮阳、机械动作。

### 8.5.3 蠕动泵（加药）⭐

- **原理**：滚轮挤压软管推进液体，**流量与转数成正比**、且液体不接触泵体（防污染/腐蚀）。
- **用途**：pH 上/下调、营养液的**定量加药**——配合水质传感形成闭环（[第 10 章](10-hub-and-automation.md)）。

## 8.6 执行器清单与用途

| 执行器 | 用途 | 驱动 |
|---|---|---|
| 主循环泵 | 水循环（CHOP2 唯一动力） | 继电器(AC)/MOSFET(DC) |
| 打氧泵 | 增氧（高温/夜间兜底） | 继电器/MOSFET |
| 电磁阀 | 分流/隔离/自动补水 | MOSFET + 续流二极管 |
| 风扇 | 水面蒸发降温、电控散热 | MOSFET(PWM) |
| 植物灯 | 补光、光周期 | MOSFET(PWM)/恒流 |
| 蠕动泵 ×2 | pH/营养加药 | MOSFET/步进 |
| 喂食器 | 定量投喂 | 舵机/步进 |
| WS2812 | 状态指示灯 | 数字信号直驱 |

## 8.7 失电默认状态与联锁 ⚠️

- 定义每个执行器**失电/复位时的默认状态**（fail-safe state）。例：加药泵默认**关**（防失控过量加药）；主泵视策略而定。
- **软件联锁**：加药前必须有近期有效 pH 读数；加药有**单次上限与冷却时间**，防传感器坏值导致过量投加（这是自动化里最危险的回路，见 [第 18 章](18-risk-and-safety.md)）。
