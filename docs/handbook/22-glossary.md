# 第 22 章 · 术语表 Glossary

> 给协作者与复刻者的速查。

## 系统 / 水路

- **鱼菜共生 Aquaponics**：水产养殖 + 无土栽培的闭环。
- **CHOP2**：Constant Height One Pump，恒水位单泵——单泵在最低集水桶，其余靠重力。
- **Sump 集水桶**：系统最低点的水箱，泵在此，兜底所有回流。
- **钟形虹吸 Bell siphon**：纯物理"淹—排"循环装置。
- **竖管溢流 Standpipe**：靠竖管高度决定缸水位、溢流多余水。
- **旋流沉淀 Swirl filter**：离心去固体的圆桶前置过滤。
- **水箱接头 / Uniseal**：塑料箱平壁 / 圆桶弧壁的过管密封件。
- **NFT / DWC**：营养液膜栽培 / 深水浮筏栽培。

## 生物 / 水质

- **氮循环**：氨 → 亚硝酸盐 → 硝酸盐 的微生物转化。
- **硝化细菌**：完成上述转化的细菌。
- **开缸 Cycling**：养出硝化菌群的过程（2–4 周）。
- **DO 溶解氧**：水中溶氧量，高温骤降是头号杀手。
- **EC / TDS**：电导率 / 总溶解固体，养分浓度代理。
- **ORP**：氧化还原电位。
- **叉尾斗鱼**：广东本土、耐热、有迷鳃可呼吸空气的鱼。

## 电子 / 控制

- **ESP32**：带 WiFi 的双核 MCU，节点主控。
- **ESPHome**：声明式（YAML）ESP32 固件框架，支持 OTA。
- **MQTT**：轻量发布/订阅消息协议，本项目的"神经"。
- **Home Assistant (HA)**：开源家庭自动化中枢。
- **ADS1115**：16 位 I²C ADC，用于干净读取模拟水质信号。
- **INA219/226**：I²C 电流/功率监测（分流法）。
- **DS18B20**：1-Wire 数字温度传感器。
- **MOSFET / 续流二极管**：电子开关 / 保护感性负载的二极管。
- **PWM**：脉宽调制，调速/调光。
- **迟滞 Hysteresis**：双阈值控制，防频繁开关。
- **PID**：比例-积分-微分闭环控制。
- **MPPT / PWM 控制器**：太阳能充电控制器两类，前者跟踪最大功率点。
- **ADR**：架构决策记录。
- **CHOP2 / MVP / RACI / SemVer**：见对应章节。
