# 第 11 章 · 数据、可视化与智能（M8 / M9）

> 草稿。负责人：系统/软件。这一层把"能跑"升级成"能看、能懂、会思考"。

## 11.1 职责与边界

- **M8 数据**：长期时序记录 + 可视化。
- **M9 智能**：视觉识别、行为分析、LLM 辅助。
- 这两层属 L3/L4，**失效不影响控制**（呼应分层约束）。

## 11.2 时序数据：InfluxDB 🔬

- **时序数据库(TSDB)** 专为"带时间戳的测量"优化：高写入、按时间聚合、保留策略（降采样/过期）。
- HA 可把实体历史写入 InfluxDB。
- 关键设计：measurement/tag/field 结构；保留策略（原始高频短期存、降采样长期存）。

## 11.3 可视化：Grafana ⭐

- 连 InfluxDB 做"作战室"仪表盘（SCADA 风格），契合工业审美。
- 典型面板：
  - **氮循环曲线**（氨/亚硝酸盐/硝酸盐随时间）——开缸期的"科学时刻"。
  - 水温/DO/pH/EC 趋势与阈值线。
  - 太阳能发电、电池电量、各路电流。
  - 泵流量 / 虹吸周期（预测维护）。
- 仪表盘 JSON 导出入 [`data/grafana/`](../../data/grafana/)，可复刻。

## 11.4 视觉：摄像头 + Frigate 🔬

- **ESP32-CAM / 树莓派 Camera** 提供画面。
- **Frigate**：本地 NVR + 目标检测（可配 Coral/Jetson 加速），事件回 HA。
- 用途：鱼缸监控、投喂记录、延时摄影（植物生长/开缸）。

## 11.5 计算机视觉与 AI（进阶）🔬

- **鱼行为分析**：检测活跃度、投喂响应、异常（浮头=缺氧预警）。方法从简单帧差/运动量，到轻量目标检测/跟踪。
- **本地算力**：Jetson Nano / Google Coral USB 做端侧推理，隐私友好、免上云。
- **LLM 日报**：把当天数据喂给（本地/云）LLM，生成自然语言"实验室日报"（"今日水温峰值 33.2°C，风扇工作 4 h，鱼投喂后 12 s 内响应，状态良好"）。

## 11.6 数据即科学

- 把每个假设变成可记录的实验：A/B 缸对照（加光/不加光）、滤材换型前后对比、开缸曲线。
- 数据留存 + 版本化（导出样例入 `data/`），让复刻者能对照。
