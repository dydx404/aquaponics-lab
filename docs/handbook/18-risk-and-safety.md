# 第 18 章 · 风险与安全

> 稳定。安全是硬约束，不是可选项。涉及水、电、高温与活体。

## 18.1 安全总原则

1. **水电分离 + 低压优先**：能 12V 解决绝不上市电。
2. **市电必带漏电保护(RCD)** + 滴水弯 + 防水。
3. **失效安全**：任何自动化都要有失效后的安全默认态（铁律一）。
4. **活体优先**：设计与决策以不伤害活体为底线。

## 18.2 电气安全 ⚡⚠️

- 220V 部分：漏电保护开关、防水插座、电线滴水弯、接头远离水。
- 12V：电池正极加保险；每支路加保险；共地。
- 锂电必配 BMS；铅酸防过放。
- 电控箱 IP65，置于水管**下方**做滴水弯。
- 潮湿环境布线用硅胶线，接头做防水（航空插头/热缩）。

## 18.3 水安全 💧

- 溢流/换水引地漏；漏水传感器 → 告警。
- 集水桶留足停泵回流余量（装好手动断泵实测）。
- 泵回水防倒虹吸。
- 结构承重与防倒（[第 5 章](05-mechanical.md)）。

## 18.4 热安全 🌡️

- 夏季高温 → DO 骤降是头号杀手：降温级联（降温 + 增氧）。
- 电子/电池散热；避免暴晒电控与电池。

## 18.5 化学/加药安全 ⚠️（最危险的自动化回路）

自动加药若失控会毒死整缸：
- 加药前**必须有近期有效 pH 读数**（前提校验）。
- **单次限量 + 冷却时间**，防坏值导致过量。
- 加药泵失电默认**关**。
- 标定过期 → 禁用加药自动化。

## 18.6 动物福利 🐟

- 放鱼前完成开缸（防氨中毒）。
- 密度/投喂适度。
- 失效安全 = 对活体负责，不是可选项。

## 18.7 数据/隐私与开源安全

- 公开仓库**绝不提交** secrets/密码/密钥/家庭住址/可定位信息（CI 守卫）。
- 摄像头画面注意隐私，避免拍到邻居/室内敏感区域，本地处理优先（Frigate/端侧）。

## 18.8 风险登记表（Risk Register）

| 风险 | 可能性 | 影响 | 缓解 |
|---|---|---|---|
| 停电夜间缺氧 | 中 | 高（死鱼） | 斗鱼耐缺氧 + 电池备用打氧 + 告警 |
| 水泵堵/坏 | 中 | 中 | 电流/流量监测 + 告警 + 旋流前置 |
| 漏水淹阳台/楼下 | 低 | 高 | 引地漏 + 漏水传感 + 集水桶余量 |
| 自动加药失控 | 低 | 高 | 联锁 + 限量 + 冷却 + 失电关 |
| 市电漏电触电 | 低 | 极高 | RCD + 低压优先 + 防水 |
| 夏季高温 | 高 | 高 | 降温级联 + 遮阳 + 耐热鱼 |
| 结构倒塌 | 低 | 高 | 重物落地 + 固定 + 承重核算 |
| 传感器坏值误触发 | 中 | 中 | 范围校验 + 联锁 + 冗余 |

## 18.9 应急预案

- 泵停/告警 → 手动增氧、检查、必要时换水。
- 漏水 → 断泵、断电、清理、查源。
- 触电风险 → 先断总电再处理。
