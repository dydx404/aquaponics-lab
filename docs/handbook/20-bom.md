- **水质**：pH / EC / DO / ORP 电极 + 隔离模块、浊度、`ADS1115`
- **通用**：`DS18B20`×4–5、`SHT31`/`BME280`、`BH1750`、水位（浮球+超声波/投入式）、`YF-S201`、`INA226`/`ACS712`、`HX711`+称重、`DS3231`

- **视觉/显示**：`ESP32-CAM`、树莓派 Camera、OLED、`WS2812`
- **电源/连接/防水**：DC-DC 降压、`GX16` 航空插头、cable gland、端子、防水盒
