## 模板

```markdown
# ADR-XXXX · 标题

- 状态：提议 / 已采纳 / 已废弃 / 被 ADR-YYYY 取代
- 日期：YYYY-MM-DD

## 背景
面临什么问题、约束是什么。

## 决定
选择了什么。

## 理由
为什么这样选，比较过哪些方案。

## 后果
带来的好处、代价、后续要注意的点。
```
