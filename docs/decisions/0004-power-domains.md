# ADR-0004 · 供电分域：220V 市电泵 + 12V DC 控制系统

- 状态：已采纳
- 日期：2026-08-06

## 背景

最初设想全系统 12V DC 母线、太阳能优先驱动包括泵在内的所有负载。但现有太阳能仅 ~20–30W，带不动泵连续运行；泵又是最关键、最大功率的负载。

## 决定

供电分两个物理隔离域：

- **市电域 220V AC**：主循环泵（及打氧等大功率负载），经漏电保护(RCD)。
- **控制/电子域 12V DC**（太阳能 + 电池 → DC-DC 5V/3.3V）：ESP32、树莓派、传感器、12V 轻载(阀/风扇/LED)。

泵由节点弱电控制信号经**继电器/固态继电器(SSR)**通断（弱电控强电）。

## 理由

- 泵走市电：可靠、不受阴雨/电量影响；20–30W 太阳能本就带不动泵。
- 控制系统走 12V：功耗小，太阳能足以支撑 → "离网"目标聚焦控制系统。
- 低压在水边更安全；两域隔离降低触电风险。
- 失效安全：市电失效时，电池仍能维持 ESP32 + 传感 + 打氧告警。

## 后果

- 节点板 / 12V 域不承载泵功率；泵控制只出一路信号给外部继电器/SSR。
- AC 与 DC 在电控盒内分区、隔离、分别走线。
- "太阳能优先调度"重定义为只针对 12V 控制域。
- 需同步更新第 3 / 6 / 8 / 13 章与接口契约。
