# ADR-0010 · 市电安全接地（ADR-0004 的安全补集）

- 状态：已采纳
- 日期：2026-08-06
- 来源：硬件评审 v2 · N-3

## 背景

[ADR-0004](0004-power-domains.md) 使 **220V 泵长期浸水**成为确定事实：水经管路连通所有缸，缸与电控盒都装在**碳钢货架**上，同一缸水里还泡着 pH/EC/浊度电极。若泵绝缘失效 → 货架整体带电，而**没有对地通路时 RCD 不会动作**，直到有人触碰。

⚠️ ADR-0004 的"两域隔离降低触电风险"**只降低了板级风险，未降低水体风险**（泵还在水里）——这两件事必须分开说，别让分域给人"安全已解决"的错觉。

## 决定（强制，写进 [第 18 章](../handbook/18-risk-and-safety.md)）

1. **货架 PE 保护接地 = 强制项**（不是可选）。没有它，泵绝缘失效 → 整架带电、RCD 不跳。
2. **集水桶接地探针 = 强制项**，作用是**主动制造跳闸**：给漏电流一条对地通路，让 RCD 在人接触之前跳。这是安全装置，不是降噪措施。
3. **单点接地**：12V 系统地与 PE 只在一点相连，避免地环流串进电极测量（呼应 [P1-4]）。

## 后果

- 第 18 章新增强制接地条款 + "AC/DC 分域未降低水体风险"的澄清。
- 漏水/触电相关风险行更新（市电泵漏电流入水 = 人身/活体安全 + 电极共模干扰）。
- 硬件侧按此设计接地与单点连接。
