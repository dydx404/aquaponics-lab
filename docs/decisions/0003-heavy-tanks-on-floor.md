# ADR-0003 · 重物落地：弱层板下的载荷布局

- 状态：已采纳
- 日期：2026-08-04

## 背景

选定的碳钢角钢货架（100×50×118 四层，¥90）实测卖家标称**单层平铺承重仅 70–80 斤（约 35–40kg）**。而一个装满水的中型缸可达 60–70kg，直接放层板有压弯 / 坍塌风险。

## 决定

**重物落地**：集水/生化桶与较大的缸放地面，不压层板；货架层板只放轻模块（小玻璃缸、生化桶、种植床/NFT、植物灯）。

## 理由

- 弱层板扛不住满水大缸，安全第一（涉及活体与人身）。
- 重物落地 → 重心更低、更稳、更抗台风。
- 与 CHOP2、多小缸方案天然契合。

## 后果

- 缸长 ≤40cm 上层板（满水 <40kg）；≥50cm 落地。
- 放水的层板一律垫木板分散压力 + 防锈。
- 也可选加固层板（垫整板 + 中间加立柱顶到地面），本项目优先"落地"方案。
