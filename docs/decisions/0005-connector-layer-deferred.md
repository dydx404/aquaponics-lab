# ADR-0005 · 接口契约分层：电气冻结 / 物理连接器延后

- 状态：已采纳
- 日期：2026-08-06

## 背景

初版接口契约把"所有传感器统一 GX16 航插"写死。但连接器一部分由**传感器本身**决定（pH = BNC、I²C 模块 = 排针/JST、DS18B20 = 三线成品、部分探头固定线长），且不同信号的**布线长度**约束差异极大（I²C 很短、1-Wire 可几米、模拟高阻需就地放大）。一刀切航插既不适用也不现实。

## 决定

接口契约拆两层：

- **电气/逻辑层（现在冻结）**：供电轨、逻辑 3.3V、总线类型(I²C / 1-Wire / 模拟经 ADS1115 / 脉冲)、上拉、续流二极管、MQTT 主题。与具体传感器无关。
- **物理连接器 + 引脚层（延后）**：等真传感器到手，按其原生接口与线长逐个定。航插只用于"要防水/可插拔/户外"的场合。
- PCB 一律做**连接器无关**：总线引到通用排针/端子，再用转接线接各传感器。

## 理由

- 连接器由传感器与线长共同决定，过早冻结会导致返工/不适配。
- 分层后"确定的部分"能马上冻结并开工，"不确定的部分"不阻塞。
- "节点靠近传感器、短线"从架构上化解长线问题。

## 后果

- node-baseboard PCB 改为连接器无关；连接器不由硬件方锁定。
- 待元件到手后，逐个传感器确定物理接口与线长，再补附录第 21 章。
- 第 13 章接口契约升级为 v2。
