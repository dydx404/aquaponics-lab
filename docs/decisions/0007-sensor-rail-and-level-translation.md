# ADR-0007 · 传感轨 3.3V + 电平转换责任方（底板）+ 连接器防误插

- 状态：已采纳
- 日期：2026-08-06
- 来源：硬件设计评审（EE）P0-2 / P0-3

## 背景

评审指出契约两处结构性漏洞：

1. **5V/3.3V 责任方未定**：第 13 章定 GX16 针 1 = +5V、逻辑电平 = 3.3V，并写"5V 器件需电平转换"，但**没说由哪一侧做**。这正是 [第 1 章前言](../handbook/01-preface.md) §1.2 举的第一个事故——"两人对 5V 还是 3.3V 理解不同 → 烧板子"。ESP32 GPIO 非 5V 容忍，5V 上拉直灌就烧。
2. **同壳不同信号**：同一种 GX16-4 可被定义为 I²C 或"信号"，两个物理可互插的口承载不同信号 → 插错把运放输出短到总线 / 把 5V 灌进 ADS1115，与 [第 2 章](../handbook/02-vision-and-principles.md) 铁律二"插上即用"冲突。

## 决定

- **传感轨默认 3.3V。** 需要 5V 的器件（YF-S201 流量、JSN-SR04T Echo、WS2812）单独走一路 5V 供电，**信号侧由底板强制提供（双向）电平转换**（如 BSS138）。**责任方 = 底板**，板子按"默认有转换"设计。
- **连接器一壳一信号类**：一种外壳只承载一类信号（I²C 一种、模拟/数字另一种），物理上无法互插；若不得不同壳，则用不同键位 + 颜色 + 丝印端口编号 + 附录登记。
- **v0.1 板级对外先不上 GX，用端子排/排针**，把连接器决策与布板解耦（不阻塞开工）；GX 定型后再上。

## 理由

明确责任方消除"烧板子"事故；3.3V 轨最安全；物理防误插落实铁律二；端子排让 v0.1 不必等连接器定稿。

## 后果

- 第 13 章补"传感轨 3.3V + 电平转换责任 = 底板 + 连接器防误插"。
- node-baseboard 按"默认带电平转换"设计。
- 细化 [ADR-0005](0005-connector-layer-deferred.md) 的连接器层。
