# ADR-0006 · I²C 只在盒内；对外线缆的缓冲 / 线材 / 最大长度

- 状态：已采纳
- 日期：2026-08-06
- 来源：硬件设计评审（EE）P0-1

## 背景

初版接口契约一度把 I²C 定为对外航空插头的标准接口，但手册 [第 16 章](../handbook/16-testing.md) §16.3 自己的调试经验写着"I²C：线太长/无上拉会失联"。技术上 I²C 为板上 <30cm、总线电容 <400pF 设计；2–3m 无屏蔽线且旁边走泵的电机线 → NACK、误码、SDA 卡死。更严重的是它**无故障隔离**：任一进水传感器把 SDA 拉死，该节点上所有 I²C 传感同时失效，与 [第 9 章](../handbook/09-firmware.md) §9.2"故障隔离"冲突。

## 决定

- **I²C 只在电控盒内**（节点板附近，≲30cm）。
- 对外长距离一律走**耐长线**的接口：1-Wire（DS18B20）、干接点（浮球/漏水）、**就地放大后**的点对点模拟、脉冲（流量）。
- 确需对外 I²C 时：每口预留 **P82B715 缓冲 footprint**（默认 0Ω 旁路、不 populate），规定屏蔽双绞、SDA/SCL 各配 GND、并在附录登记最大线长。

## 理由

把 I²C 限制在其可靠工作域；用"一模块一节点、节点靠近传感器"从架构上化解长线（呼应 [ADR-0005](0005-connector-layer-deferred.md) 的"节点靠近传感器、短线"）。

## 后果

- 传感器要么靠近节点（I²C），要么改用长线友好接口。
- [第 21 章附录](../handbook/21-appendix-pinouts.md) 补各接口最大线长。
- 缓冲 footprint 可选贴装，不增加默认成本。
