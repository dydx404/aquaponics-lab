# ADR-0001 · 采用 CHOP2 单泵闭环

- 状态：已采纳
- 日期：2026-08-04

## 背景

阳台空间与预算有限，且需要长期无人值守运行。水泵是系统最可能失效、也是最耗电的部件。

## 决定

采用 **CHOP2（Constant Height One Pump，恒水位单泵）**：全系统只有一个水泵在集水桶，其余水流全靠重力。

## 理由

- **单一故障点最小化**：只有一个泵要维护 / 监控。
- **恒水位 + 集水桶兜底**：泵停时缸不被抽干、水回落到集水桶不外溢。
- **省电**：单泵符合 12V 太阳能离网目标。
- 对比：多泵各缸独立循环，布线/耗电/故障点都翻倍，不值。

## 后果

- 集水桶必须留足空位接住停泵回流水（失效安全前提）。
- 泵扬程必须足够把水抬到顶层（≥2.5–3m）。
- 各缸需要定水位溢流（竖管 / 缸口溢流）。
