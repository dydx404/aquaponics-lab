# ADR-0002 · 多口小玻璃缸「实验鱼房」而非单一大缸

- 状态：已采纳
- 日期：2026-08-04

## 背景

最初计划用一个大塑料周转箱当鱼缸。但项目目标是"可玩、可实验、可迭代"，且用户已有 40cm、30cm 玻璃缸，还能低价淘到更多小缸。

## 决定

改为**多口小玻璃缸并联**在同一循环上，每口缸是一个可热插拔的实验单元。

## 理由

- **可做实验**：A 缸鱼、B 缸水培、C 缸虾、D 缸对照，可 A/B 对比——这才是"实验室"。
- **全透明**：玻璃缸看得见水流、鱼、根系，符合工业风「可见管路」。
- **重量友好**：小缸满水轻，弱层板扛得住（见 ADR-0003）。
- **真模块化**：加缸 = 接一个球阀分支；拔缸不影响其他。

## 后果

- 玻璃缸尽量不钻孔（可能钢化会炸）→ 走缸口 / 背挂溢流。
- 需要供水总管 + 回水总管（略增管路），换来独立控制与可扩展。
- 水量分散，单缸生物负载低，更稳。
