# 01 · 布局与货架 Layout & Rack

## 货架

- 碳钢角钢货架 **100(长) × 50(宽) × 118(高)，四层**，葫芦卡扣层高可调（约 2.5–5cm 一档）。
- 单层平铺承重仅 **~35–40kg**（弱，见 [ADR-0003](../decisions/0003-heavy-tanks-on-floor.md)）。

## 落位原则

- **重物落地**：集水/生化桶 + 主玻璃缸放地面，不压层板。
- **层板只放轻的**：小玻璃缸（缸长 ≤40cm）、生化桶、种植床/NFT、植物灯。
- 缸长 **≤40cm 上层板**（满水 <40kg）；**≥50cm 落地**。
- 放水的层板一律**垫木板**：分散压力 + 隔开碳钢防锈。
- 靠实心墙、脚下垫橡胶/木板护瓷砖；顶部与墙/栏杆做固定防台风。

## 广州特化

- 朝向东南：上午直射为主、避开西晒，夏季控温相对友好。
- 夏季高温是头号风险：遮阳 + 水面风扇蒸发降温 + 加强打氧（自动化级联，见 build 文档）。
- 太阳能板与喜阳植物放玻璃栏杆（东南）侧；鱼缸放阴面/被上层遮挡处。

## 重量与结构

满水估算（多缸 + 桶）约 100–150kg，集中在靠墙 0.5m² 内，普通阳台可承受，但务必：
- 重心压低（重物落地）。
- 载荷分散到木板 / 托盘，避免点载压裂瓷砖。
