# 01 · 水路设计 Water Loop (CHOP2)

## 拓扑

单泵闭环，水的走向：

```
集水/生化桶(单泵) → 泵上顶 → 供水总管 → 各玻璃缸 → 缸口/竖管溢流
        → 底部回水总管 → 回集水/生化桶  ↺
```

- **集水/生化桶**：落地。既是 sump 又装生化滤材。泵在此。
- **供水总管**：顶部一根横管，每口缸接一个 T + **球阀**滴下水（可单独调流量/隔离一口缸）。
- **各缸溢流**：竖管定水位——竖管多高、水位就多高，多余水溢走。
- **回水总管**：底部横管，收集各缸溢流回集水桶。

## 过滤三段（顺序不能乱）

1. **物理过滤**（在前）：过滤棉，拦鱼粪、残饵。勤洗（只用旧缸水）。
2. **生化过滤**（在后）：细菌屋 / K1，养硝化细菌，氨 → 亚硝酸盐 → 硝酸盐。**几乎不洗，绝不用自来水冲**（氯杀菌）。
3. （可选）化学过滤：活性炭，短期除味除黄。

## 玻璃缸不钻孔

便宜玻璃缸多为钢化，钻孔易炸。**改走缸口 / 背挂 U 型溢流**，不破坏玻璃。只有塑料的集水桶、生化桶才钻孔——平壁用**水箱接头**，圆桶用 **Uniseal 柔性圈**。

| 管径 | Uniseal 开孔 | 水箱接头开孔（按丝口） |
|---|---|---|
| 20mm(4分) | ~32mm | 4分 → ~22mm |
| 25mm(6分) | ~40–43mm | 6分 → ~28mm |
| 32mm(1寸) | ~50mm | 1寸 → ~34mm |
| 50mm(排水) | ~68–73mm | — |

> 具体开孔尺寸以接头卖家标注为准，各家差 1–2mm。

## 失效安全

- **集水桶留足空位**：停电时缸内高于溢流口的水 + 管中存水会倒流回集水桶，桶必须能接住不外溢。装好后手动断泵实测一次。
- **泵回水口防倒吸**：留在水面以上或钻防虹吸孔，避免停泵把缸抽干。
- **溢流引地漏**：总溢流 / 换水用软管引到阳台地漏。

## 泵选型

12V DC、**扬程 ≥ 2.5–3m**、流量 600–1000L/h（要把水抬到 ~1m 顶层并留余量）。
过渡期可先用市电 25W 泵（走漏电保护），离网阶段再换 12V。
