## 分工（v2，已定）

- **硬件（含 PCB 设计 + 开发板选型）** → 远程协作者（福州）。板子怎么设计、用哪块开发板，**他决定**。
- **软件（固件 + Home Assistant + 自动化 + 数据 + 终端 UI）** → 项目发起者。
- **唯一交叉约束**：开发板必须是 **ESPHome 兼容的 ESP32 家族**（软件栈依赖它），且对外满足[接口契约](handbook/13-interfaces.md)。除此之外：板型细节归硬件、软件不干涉；软件栈归软件、硬件不干涉。

## E. 供电 Power

- **220V 泵域**：RCD + **主泵机械继电器(NC)**（SSR 仅用于打氧/灯，已在用市电）· **12V 控制域**：太阳能+电池+DC-DC 5V/3.3V。
- 能量监测（INA226）· IP65 电控盒理线（AC/DC 分区）。详见 [ADR-0004](decisions/0004-power-domains.md)、[第 6 章](handbook/06-power.md)。

## F. 安全/失效 Safety

- **物理兜底**：虹吸/溢流/集水桶余量/缺水浮球（零电力）。
- **电气**：RCD、保险、续流二极管、AC/DC 隔离。
- **逻辑**：加药联锁+限量、坏值防护、断泵回流余量。
- **动物福利**：开缸达标后放鱼、密度/投喂适度。详见 [第 18 章](handbook/18-risk-and-safety.md)。

## G. 生态/生物 Bio

## PCB 预留位（由 B 类推导，硬件方据此留位，全部可选贴装）

- **~4 路 12V 低边 MOSFET**（IRLZ44N + 续流二极管 + 栅极下拉）—— 打氧 / 加药 / 风扇 / 灯。
- **2 个舵机/PWM 头**（5V/GND/PWM）—— 喂食 / 遮阳。
- **2 路"控制信号"输出**（`PUMP_STOP` 等）→ 主泵走**机械继电器(NC)**；气泵/灯等不需 NC 的 220V 负载可用 SSR 或改派的 WiFi 继电器（弱电控强电，见 [ADR-0009](decisions/0009-pump-metering-and-control.md) R-4）。
- **WS2812 口** —— 状态灯。
- **SPI 排针** —— 未来触摸墨水屏终端 / 显示。
- 传感侧：**I²C 总线 + 1-Wire(XH) + N 路模拟经 ADS1115**（ADS1115 可选贴装或模块，硬件方定）。

## 连接器方案（已定）

| 场景 | 连接器 |
|---|---|
| 数字/温度/I²C（DS18B20、BME280、BH1750…） | **JST-XH 2.5mm**（1-Wire 3P；I²C 4P：VCC/GND/SDA/SCL） |
| pH/EC/ORP 探头 | **BNC** → 各自放大模块 → 模拟 → ADS1115 |
| 防水/户外/入水/12V 负载 | **GX 航插** |
