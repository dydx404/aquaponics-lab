## B. 电子 · 传感 · 执行

> 详细采购/型号见 issue「元件采购」。核心清单：

- 水质：pH / EC / DO / ORP 电极 + 模块、浊度、`ADS1115`（16位 ADC）
- 通用：`DS18B20`×4–5、`SHT31`/`BME280`、`BH1750`、水位（浮球 + 超声波/投入式）、`YF-S201` 流量、`INA226`/`ACS712` 电流、`HX711`+称重、`DS3231` RTC
- 执行：继电器板、MOSFET(`IRLZ44N`)、电机驱动(`A4988`/`L298N`)、舵机/步进、蠕动泵、12V 电磁阀
- 视觉/显示：`ESP32-CAM`、树莓派 Camera、OLED、`WS2812`
- 电源/连接/防水：DC-DC 降压、航空插头 `GX16`、防水接头(cable gland)、端子、防水盒
